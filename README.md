# Конвертер температур с историей операций

## Описание проекта

Учебная консольная программа на Python для конвертации температур между шестью шкалами. Программа проверяет физическую допустимость значений, сохраняет историю успешных операций и умеет обрабатывать несколько конвертаций из текстового файла.

## Возможности

- конвертация температур между любыми поддерживаемыми шкалами;
- поддержка Цельсия, Фаренгейта, Кельвина, Реомюра, Ранкина и Делиля;
- проверка абсолютного нуля с учётом направления шкалы Делиля;
- ввод целых и дробных чисел;
- поддержка десятичной точки и запятой;
- отклонение `nan`, `inf`, `+inf` и `-inf`;
- история операций в UTF-8;
- просмотр истории из меню;
- пакетная обработка файла `input.txt`;
- сохранение отчёта пакетной обработки в `output.txt`;
- автоматические тесты на `pytest`.

## Поддерживаемые шкалы

| Обозначение | Шкала |
|-------------|-------|
| C | Цельсий |
| F | Фаренгейт |
| K | Кельвин |
| Re | Реомюр |
| R | Ранкин |
| De | Делиль |

## Использование

Пример главного меню:

```text
====================================
       КОНВЕРТЕР ТЕМПЕРАТУР
====================================

1. Конвертировать температуру
2. Просмотреть историю
3. Пакетная конвертация из файла
4. Справка по шкалам
0. Выход
```

Пример конвертации:

```text
Введите температуру: 36.6

Результат:

36.60 °C = 97.88 °F

Операция сохранена в истории.
```

## Пакетная конвертация

Файл `data/input.txt` использует формат:

```text
значение;исходная_шкала;целевая_шкала
```

Пример:

```text
25;C;F
100;C;K
32;F;C
80;Re;C
```

Каждая непустая строка обрабатывается независимо. Ошибка одной строки не останавливает обработку остальных. Результат также записывается в `data/output.txt`.

## История

Каждая успешная конвертация добавляется в `data/history.txt`, например:

```text
2026-08-16 12:45:13 | 36.60 °C -> 97.88 °F
```

Файл открывается в режиме добавления, поэтому предыдущие записи сохраняются между запусками программы.
